# i18n — TJFit

## Supported locales (do not remove any)

`en`, `tr`, `ar`, `es`, `fr`

- `ar` is RTL — verify `dir="rtl"` propagates and Tailwind logical properties (`ms-`, `me-`, `ps-`, `pe-`) are used over `ml-`/`mr-`.
- `tr` and `fr` require diacritics — see commit `3711484` (TJAI hub) for the pattern. Do not strip accents.

## Dictionaries

- Translations live in `src/lib/i18n.ts` (`dictionaries` export) plus the standalone `*-copy.ts` modules. The old `messages/*.json` + `src/lib/messages.ts` Phase-2 layer was archived (zero call sites) — see `docs/i18n-archive/README.md`.
- Keys must exist in ALL locales. Missing keys cause runtime fallback to `en`, which the owner considers a bug.
- When adding a key: add it to all 5 locales in the same commit, even if some values are placeholder English.

## Rules

- Do NOT modify dictionaries on a task that isn't explicitly a translation task.
- Do NOT remove keys; mark unused ones for follow-up instead.
- Do NOT hard-code user-facing strings in components — always go through the dictionary.
