| `"image/*"` (file-input MIME) | 1 | MIME type, universal. |
| `"you@example.com"` placeholder | 1 | **Borderline** — could localize, but `you@example.com` is universal email-format convention used across most i18n product UIs. Leaving as-is. |

## Decision

- **No source files edited** for Phase 14.
- **No translations added.**
- The `i18n:verify` failure is entirely scanner noise. The scanner should be tuned to skip:
  - JSX attribute names (regex anchor `\w+=`)
  - SVG inline attributes
  - CSS / Tailwind arbitrary-value strings (`rgba(`, `linear-gradient(`, `conic-gradient(`, `drop-shadow(`, `clamp(`, `bg-[`, `border-[`, `shadow-[`)
  - Strings shorter than e.g. 4 alphabetic chars
  - SQL column-name lists (`select(...)` argument literals)
  - Template-literal expression fragments (`"} ${" / "? <"`)

Scanner tuning lives in [scripts/i18n/check-hardcoded-ui.ts](../../scripts/i18n/check-hardcoded-ui.ts) (132 LOC) — out of scope for this loop fire per CLAUDE.md §4 ("No unrequested refactors").
